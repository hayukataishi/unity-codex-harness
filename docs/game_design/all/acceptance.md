# ゲーム全体受け入れ条件

ゲーム全体、複数Scene、Build、起動から終了までのPlayer journeyに関わる要求を
記録します。Scene内だけで完結する要求は各Sceneの`acceptance.md`へ記録します。

## 記入ルール

- ACは設計より先に発行し、観察可能な合否を一つだけ書く。
- `Approved`へ進める前に検証種別、検証方法、承認者・日付を確定する。
- `Approved` ACには一つ以上の関連設計IDを割り当てる。
- 実装方法、class名、Prefab構成などの解決策はACへ書かない。
- 発行済みIDは変更・再利用せず、不要時は`廃止`にする。
